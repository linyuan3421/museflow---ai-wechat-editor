## 💡 产品核心定位

MuseFlow 是一款**专为多平台内容创作者打造的"美学转换引擎"**。

我们解决的核心矛盾是：**创作者旺盛的表达欲 vs 匮乏的设计能力与排版精力**。

用户只需专注于 Markdown 纯文本写作，MuseFlow 负责利用 AI 将其"翻译"为微信公众号的精美排版，或小红书的视觉卡片。

---

## ✨ 核心功能模块

### 1. 🎨 双模渲染引擎

这是我们区别于传统 Markdown 编辑器的最大护城河。

#### Mode A：微信公众号流式排版
- **原理**：将 Markdown 实时编译为带内联样式（Inline CSS）的 HTML
- **价值**：完美绕过微信后台限制，保留"杂志级"的排版质感
- **体验**：375px 仿真预览，所见即所得，一键复制格式不乱

**内置 6 款精选主题**：
| 主题 | 风格 |
|------|------|
| 先锋杂志 | 极简黑白，大胆排版与留白 |
| 山野迷雾 | 森系配色，低饱和度绿与灰 |
| 岛屿假日 | 蔚蓝与流沙，地中海式清爽 |
| 旧日玫瑰 | 莫兰迪粉与勃艮第红，复古浪漫 |
| 极简白露 | 大面积留白，克制字体排印 |
| 暖阳木质 | 大地色系，温暖怀旧咖啡馆风 |

#### Mode B：小红书卡片生成
- **原理**：智能语义拆解。AI 自动识别 Markdown 中的章节，将其拆分为 4-8 张逻辑连贯的竖屏幻灯片（3:4 比例）
- **价值**：解决"文章转图"的痛点。用户无需打开 Canva 或 PS，直接由文字生成封面、正文页、金句页
- **技术**：前端实时渲染 + 高清截图导出，支持批量下载与内容编辑

**内置 6 款卡片模板**：
| 模板 | 风格 |
|------|------|
| 黑白瑞士 | 极高对比度，网格对齐，雕塑感文字 |
| 琉光拟态 | 柔和渐变背景与半透明毛玻璃卡片 |
| 新波普 | 高饱和撞色，粗黑边框，复古拼贴 |
| 优雅笔记 | 纸张纹理，衬线体，精心设计的信纸感 |
| 水墨气韵 | 东方留白美学，写意山水，书法体点缀 |
| 胶片故事 | 电影字幕叙事感，颗粒噪点，温暖滤镜 |

### 2. 🤖 AI 灵感工坊

我们不仅提供内置的精美模版，还提供**生成模版的能力**。

#### 六大 AI 能力

| 能力 | 描述 | 应用场景 |
|------|------|----------|
| **文生主题** | 输入"赛博朋克霓虹"或"清晨的森林"，AI 实时生成全套 CSS 配色方案 | 公众号排版 |
| **图生主题** | 上传一张照片，AI 提取其色彩心理学特征，应用到文章排版 | 公众号排版 |
| **文生模板** | 输入风格描述，AI 生成小红书卡片配置（配色、装饰、字体） | 小红书卡片 |
| **图生模板** | 上传参考图，AI 提取视觉风格生成卡片模板 | 小红书卡片 |
| **格式清洗** | 一键将飞书/Word/网页的杂乱文本清洗为标准 Markdown | 通用 |
| **文章转卡片** | AI 自动识别章节结构，拆分为 4-8 张逻辑连贯的幻灯片 | 小红书卡片 |

### 3. 🧠 RAG 知识增强系统（技术亮点）

MuseFlow 内置了一套**浏览器端 RAG（检索增强生成）系统**，这是区别于普通 AI 工具的核心技术优势。

#### 架构设计
```
用户输入 "莫兰迪风格"
    ↓
[LLM 查询重写] → "莫兰迪 morandi 灰粉 低饱和 muted 高级灰"
    ↓
[Orama.js 语义检索] → 从知识库中检索最相关的配色方案
    ↓
[提示词增强] → 将精确的色值注入到 AI 系统提示词中
    ↓
[AI 生成] → 输出包含精确配色的高质量主题
```

#### 双知识库架构
- **公众号知识库**：200+ 配色方案、20 种情绪、15 个场景、质感与技法
- **小红书知识库**：独立优化的卡片设计知识，涵盖排版、装饰、字体风格

#### 核心优势
- **精确配色**：AI 不再"瞎编"颜色，而是使用知识库中精选的 hex 色值
- **设计规范**：内置 WCAG 对比度标准、移动端字号规范、间距系统
- **风格一致性**：RAG 确保"莫兰迪"生成的每次结果都在同一色系范围内

---

### 4. 🔒 隐私与自由

- **Bring Your Own Key (BYOK)**：我们不内置 AI 模型，支持用户配置自己的 API Key
- **多模型支持**：完美支持 **OpenAI GPT-4o** 以及国内主流大模型（**DeepSeek 深度求索**、**Kimi 月之暗面**、**通义千问**等）
- **本地存储**：你的草稿、自定义主题、API Key 均存储在浏览器本地，不经过任何中间服务器
- **历史记录**：IndexedDB 自动保存，每 30 秒自动备份，永不丢失

## 🚀 快速开始

### 环境要求
- Node.js >= 18
- npm 或 yarn

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/linyuan3421/museflow---ai-wechat-editor.git

# 2. 进入目录
cd museflow

# 3. 安装依赖
npm install

# 4. 启动开发服务器
npm run dev
```

打开浏览器访问 `http://localhost:5173` 即可开始创作。

## ⚙️ 模型配置指南

为了使用 AI 功能（如生成主题、清洗格式），你需要配置 API Key。

1. 点击左侧栏顶部的 **"设置" (⚙️)** 图标
2. 选择你偏好的服务商预设
3. 输入你的 API Key
   - *OpenAI:* `https://platform.openai.com/api-keys`
   - *DeepSeek:* `https://platform.deepseek.com/api_keys`
4. 点击保存。配置将仅保存在你的本地浏览器中。

## 💭 产品哲学："小而美"

### 核心价值观
1. **🎲 随机性与创造的魅力**：市面上的工具大多提供千篇一律的模版，MuseFlow 引入 AI 的"随机性"——你只需给出一个模糊的感觉，AI 就能为你生成独一无二的视觉语言
2. **⚖️ 复利思维与内容杠杆**：写作是线性的，但分发应该是指数级的。同一份 Markdown，通过 MuseFlow 可同时转化为公众号文章和小红书卡片，实现影响力的最大化
